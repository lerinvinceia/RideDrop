# 🚗 RideDrop — Carpooling App

**RideDrop** is an Android-based **carpooling and parcel-sharing application** that connects **users** and **drivers** for efficient, eco-friendly travel.  
It allows users to **book** or **offer rides** in real time, with dynamic route estimation, Firebase-based live updates, and instant SMS notifications.

---

## ✨ Highlights

- 🔐 **Firebase Authentication** for secure user login & registration  
- ☁️ **Firebase Realtime Database** for live ride data & updates  
- 🗺️ **OpenRouteService API** for real-time route generation & distance calculation  
- 💬 **SMS Notifications** for booking confirmations and ride updates  
- ⚡ **Optimized performance**, handling **30+ simulated rides per day** during testing  

---

## 🚦 Features

- 🧭 **Role-based flow** — separate dashboards for **User** and **Driver**  
- 🚘 **Post & browse rides** dynamically from Firebase  
- 📍 **Book rides** with live availability & route visualization  
- 🗺️ **Distance and time estimation** via OpenRouteService API  
- 💬 **SMS communication** for booking confirmations  
- 💳 **Razorpay integration** *(optional module for future updates)*
