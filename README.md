# 🚗 RideDrop — Carpooling App

**RideDrop** is an Android carpooling application that allows users to **book** and **offer** rides in real time.

**Highlights**
- 🔐 Firebase Authentication for secure login  
- ☁️ Firebase Realtime Database for live ride data and updates  
- 🗺️ OpenRouteService API for dynamic routes and distance calculations  
- 💬 SMS notifications for booking confirmations and driver communication  
- ⚡ Optimized to support 30+ simulated rides per day (for testing/performance)

---

## Features
- Role-based flow (User / Driver)
- Post and browse available rides
- Book rides with real-time availability updates
- Route mapping and distance estimation via OpenRouteService
- SMS notifications for bookings and updates

---

## Tech Stack
- **Language:** Java  
- **IDE:** Android Studio  
- **Database:** Firebase Realtime Database  
- **Auth:** Firebase Authentication  
- **Routing:** OpenRouteService API
